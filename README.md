# Electro Energetics AC Recipes

This datapack adds crafting recipes for all AC-related stuff from Create: Electro Energetics mod as it doesn't have them at the moment

I tried making these recipes to match EE style as mush as possible, so if you feel something doesn't fit, feel free to fork and edit it or create new issue.
